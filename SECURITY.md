# Responsible use and security reporting

RevScope is an educational directory of third-party tools. It does not execute or download samples, inspect targets, proxy traffic, or provide a hosted analysis service.

## Authorized use

Use listed tools only for software, devices, and network traffic you own or are explicitly authorized to assess. Follow local law, the owner's rules of engagement, and each tool's current terms and license. Do not use the guide to enable unauthorized access, credential theft, evasion, surveillance, or harm.

## Reporting an issue in RevScope

For a broken link, inaccurate entry, accessibility concern, or website bug, open a public GitHub issue with a concise description and steps to reproduce. Do not include secrets, personal data, exploit code against a third party, or live malware samples.

For a security concern involving this repository, contact the maintainer through the private vulnerability reporting option on GitHub when available. Avoid posting undisclosed vulnerabilities in third-party products here; use the affected vendor's disclosure process.
